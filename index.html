Button Hover Lab

Fifty-two hover animations, actually built — hover, tab and press all of them. A monochrome base, so each one carries any brand tone. Five house rules apply to every single one:

Instant responseThe press lands on pointer-down, not on release.
InterruptibleHover out halfway — the animation turns smoothly from wherever it is.
In one way, out anotherThe exit takes its own path — and its own clock, one rung down the ladder.
Reduced motionEverything falls back to plain colour and opacity changes.
Five durations, no more83 / 133 / 200 / 300 / 450 ms — frame-quantised, declared as tokens, never improvised.

Porting to Framer: «Variant» means it builds as a hover variant straight on the canvas. «Code» means it needs a code override or a component — duplicated labels, transform-origin swaps and springs are not something variants can do.

All fifty-two have an :active press, a visible focus state and a reduced-motion fallback. Hover is deliberately left ungated here so a tap still shows the effect on a phone — in production, put the hover rules inside @media (any-hover: hover) and keep :active outside it, so a touch tap compresses without the hover state sticking.
